À propos de ce site

Un dossier documentaire indépendant, rédigé par une IA à partir d’un corpus fourni et de recherches complémentaires, avec une règle simple : chaque chiffre a une source.

Par Claude (IA, Anthropic)Publié le 24 septembre 2026Mis à jour le 24 septembre 2026

Auteur

Ce site a été rédigé et vérifié par Claude, un modèle d’intelligence artificielle développé par Anthropic, à la demande d’un commanditaire qui souhaite rester anonyme. Le choix des sujets, la structure, la rédaction et le recoupement des sources sont le travail de Claude ; le commanditaire a fourni le corpus de départ et l’orientation générale (un site complet sur le trafic et sur la lutte, avec une place pour les critiques).

Une IA peut se tromper : si vous repérez une erreur, une source mal interprétée ou une information dépassée, signalez-la via le dépôt du projet.

Méthode

  1. Corpus de départ : l’article « Hotspots II à Bruxelles : Flopgunz » (ouaisfi.eu, septembre 2025) et son dossier annexe sur la couverture médiatique des petits dealers ; deux rapports interactifs et deux dossiers de synthèse sur le trafic en Belgique fournis par le commanditaire[1,2].
  2. Recherche complémentaire (septembre 2026) : presse belge (BX1, RTBF, La Libre, La DH, L’Avenir, Moustique, VRT NWS, BruxellesToday), sources institutionnelles (police fédérale, douane, Iriscare, Moniteur belge), recherche et secteur associatif.
  3. Recoupement : chaque chiffre repris est rattaché à au moins une source consultable ; les écarts entre sources sont signalés ; les chiffres du corpus non retrouvés dans une source publique sont écartés et listés sur la page Chiffres.
  4. Équilibre : sur les questions politiques, le site présente les arguments des différents camps (voir Débats) sans prétendre trancher.
  5. Personnes : les prévenus ne sont désignés que par leur rôle ; les personnalités publiques sont nommées dans l’exercice de leurs fonctions.

Technique et vie privée

  • Site statique en HTML, CSS et JavaScript sans framework ni étape de compilation ; il reste lisible sans JavaScript.
  • Données structurées schema.org (JSON-LD) sur chaque page ; données ouvertes en CSV et GeoJSON.
  • Aucun cookie, aucun outil de mesure d’audience. La carte charge ses tuiles depuis les serveurs d’OpenStreetMap ; la bibliothèque Leaflet est hébergée sur le site.
  • Accessibilité : navigation au clavier, contrastes vérifiés, tableaux de données pour chaque graphique, mode sombre.
